# Mehdi Lakhouane - Portfolio

A professional, responsive portfolio website designed to showcase my journey from a certified Road Construction Specialist (Strassenbauer) to an aspiring Software Developer. This project highlights my unique background, technical skills, and projects.

## 🚀 Features

- **Modern & Premium Design**: Built with a "dark mode" aesthetic using high-contrast colors and subtle animations to convey professionalism.
- **Responsive Layout**: Fully responsive design that works seamlessly on desktops, tablets, and mobile devices.
- **Interactive Elements**: Smooth scrolling, hover effects, and a custom mobile navigation menu.
- **Project Showcase**: specific sections to display my web development and game development projects.
- **Bilingual Context**: Highlights my trilingual abilities and diverse background.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure and accessibility.
- **CSS3**: Custom properties (variables), Flexbox, Grid, and keyframe animations. No external CSS frameworks were used to demonstrate core competency.
- **JavaScript (ES6+)**: DOM manipulation for mobile menu, scroll progress bar, and active navigation highlighting.
- **FontAwesome**: For iconography.
- **Google Fonts**: Uses 'Outfit' for headings and 'Inter' for body text.

## 🔧 Setup & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Lakhouane-Mehdi/portfolio.git
   ```
2. **Open the project:**
   Simply open `index.html` in your preferred web browser.
   
   OR

   Use a live server extension in VS Code for the best development experience.

## 🌍 Deployment

This website is ready to be deployed on platforms like **Vercel**, **Netlify**, or **GitHub Pages**.

1. Push the code to a GitHub repository.
2. Connect the repository to Vercel/Netlify.
3. Deploy!
