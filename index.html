About

I learned discipline in a trade where one wrong measurement means tearing up a road. I write code with the same care.

I'm Mehdi Lakhouane, an independent developer in Frankfurt. I came to Germany from Morocco in 2018, trained as a Straßenbauer (road builder) and taught myself software by building real things — project by project.

Because I have stood in the trench myself, I build software for people who wear gloves and have no signal: tools that work offline, on a phone, in a hurry. The same thinking goes into my AI agents, which run on your own machine and keep your data there.

  • Finish itA project that stays on my hard drive helps nobody. I build things until they can be used.
  • Learn by buildingPython, React, Flutter, Godot, C++ — I learned each one because a project needed it.
  • Real users firstSite workers, language learners, people who care about privacy. Not imaginary users.
